# 使用手冊

給實際使用這套系統的人看的。部署與環境設定請看根目錄的 [README](../README.md)。

記錄股票買賣與銀行帳戶餘額,每天自動抓收盤價與匯率,在首頁看資產配置與增長趨勢。
家人可以共用同一份資料,各自只改自己的部分。

---

## 第一次設定

照順序走完這五步,之後就只需要記錄新發生的買賣與現金進出。

### 1. 註冊帳號

填 Email、密碼與顯示名稱。密碼至少 8 個字元。

如果送出後看到「請到信箱點擊驗證信」,先去收信完成驗證再回來登入。

### 2. 建立家庭,或加入家人的家庭

第一個註冊的人選「建立新家庭」,取個名字就好。
其他家人選「加入既有家庭」,貼上第一個人給的邀請碼。

### 3. 把帳戶建起來(帳戶 → 新增帳戶)

每個銀行帳戶建一個,每個券商建一個「券商虛擬帳戶」。

| 欄位 | 說明 |
|---|---|
| 類型 | 銀行 / 券商虛擬帳戶 |
| 幣別 | 新台幣 / 美元 |
| 機構名稱 | 例如「國泰世華」「元大證券」 |
| 備註 | 選填,例如「薪轉戶」 |
| 期初餘額 | 填你**今天**的實際餘額 |
| 期初日期 | 這個帳戶的起算日 |

### 4. 導入現有持股(股票 → 新增交易 → 期初持股)

手上每一檔股票各記一筆,填目前的**股數**與**均價**,
不用把過去的買賣一筆筆補回來。期初持股不會動到任何帳戶餘額。

### 5. 把邀請碼給家人(設定 → 邀請碼)

複製那串代碼傳給家人。他們註冊後貼上,首頁就會多出「全家」視角。
只有一個人的時候不會顯示這個切換。

> **手機與電腦的版面不一樣。**
> 手機是底部五個分頁、資料以卡片呈現、表單從底部滑上來;
> 電腦是頂部導覽、完整表格、置中對話框。功能完全相同。

## 五個分頁

| 分頁 | 內容 |
|---|---|
| **總覽** | 最上方是總資產,底下四個數字:股票市值、現金、今年未實現損益、今年已實現損益。再往下是資產增長曲線、配置圓餅圖,最下方是年度損益表。可切「個人 / 全家」與期間(1 日、1／3／6 個月、年初至今、1／3／5 年,預設年初至今) |
| **日曆** | 每天的股票盈虧,上方是今年 12 個月的月盈虧,點某一天看每檔的明細 |
| **股票** | 上半是目前持股(股數、均價、現價、市值、未實現損益),下半是所有交易紀錄。右上角「新增交易」記錄買賣 |
| **帳戶** | 分成「銀行」與「券商虛擬帳戶」兩組,各自有小計。點任何一個帳戶進去看完整流水帳並新增收支 |
| **設定** | 家庭名稱與成員、邀請碼,以及資料同步狀態 —— 最新股價日期與最新匯率 |

## 記錄股票

股票 → 新增交易,三種類型擇一。
台股打代號會跳出建議清單,選了會自動帶入商品名稱;美股目前要自己填名稱。
股數與手續費欄位會邊打邊加千分位(例如 250,000),方便核對有沒有少打一個 0。

| 類型 | 什麼時候用 | 對券商帳戶的影響 |
|---|---|---|
| 期初持股 | 導入既有部位,填目前股數與均價 | **不連動** —— 代表既有部位,不是新的資金進出 |
| 買進 | 新買一筆,填成交價;台股手續費會自動帶出 | **提出** 股數 × 價格 ＋ 手續費 |
| 賣出 | 賣掉一筆,填成交價;台股手續費與證交稅會自動帶出 | **存入** 股數 × 價格 − 手續費與稅 |

台股的手續費照牌告 0.1425% 計算(無條件捨去、最低 20 元),賣出再加證交稅:
一般股票 0.3%、ETF 0.1%、債券 ETF 免徵(至 2026 年底)。**沒有算券商折扣**,
有折扣就直接改掉那個欄位;改過之後不會被蓋掉,旁邊有「改回自動計算」可以還原。

買進與賣出的表單上有「同步更新券商帳戶餘額」這個勾選,預設是打開的,
並要你選一個交割用的券商帳戶。某一筆不想連動就取消勾選 —— 那筆交易只會影響持股,不動任何餘額。

### 編輯與刪除

交易紀錄每一列右邊有「編輯」與「刪除」,只有自己的交易才會出現。

- **編輯**:改完儲存後,持股、均價、已實現損益與券商帳戶餘額會立刻重算。
  交易日期在昨天以前的話,趨勢圖與日曆會在下一次每日同步時自動重算。
- **刪除**:按一下會先問「刪除這筆買進?」,再按「確定刪除」才會真的刪掉。刪掉之後救不回來。

> **連動產生的帳戶紀錄跟著股票交易走。**
> 編輯買賣時它會自動改成新的金額,刪除買賣時它會一併消失。
> 不要到帳戶頁去改那筆自動產生的收支(也刪不掉),要改就回股票頁改原本那筆買賣。

### 均價是怎麼算的

採**移動加權平均法**。買進會把成本攤進均價,賣出不改變均價
—— 只是按均價把成本移出去,差額計入已實現損益。

以 2330 台積電為例:

| 動作 | 結果 | 算式 |
|---|---|---|
| 期初持股 1,000 股,均價 600 | 均價 600.00 | 總成本 600,000 |
| 買進 1,000 股 @ 800,手續費 400 | 均價 700.20 | (600,000 ＋ 800,000 ＋ 400) ÷ 2,000 股 |
| 賣出 500 股 @ 900,費稅 1,600 | 均價 700.20 | 均價不變,持股剩 1,500 股 |
| ↳ 這筆的已實現損益 | ＋98,300 | (500 × 900 − 1,600) − (500 × 700.20) |

賣光之後再買進,均價會用新的買進價重新起算,但已實現損益是累計的,不會歸零。

## 記錄現金

點進任一帳戶,用「新增收支」記錄。帳戶之間搬錢則用帳戶頁上方的「轉帳」。

| 類型 | 什麼時候用 |
|---|---|
| 存入 | 薪資、利息、他人匯入等進帳 |
| 提出 | 提款、繳款、消費等出帳 |
| 對帳調整 | 帳面跟實際對不起來時補的一筆。**金額可以填負數**,而且請務必寫明原因 |
| 轉帳 | 帳戶之間搬錢。成對記錄(一邊轉出、一邊轉入),總資產不變。只能在自己的帳戶之間轉 |

流水帳的每一列都有「結餘」,是從期初一路累加到那一筆的餘額,
方便你跟銀行對帳時逐筆核對。

> **不要回頭改舊紀錄。**
> 銀行給的利息、忘了記的一筆提款、跨行手續費 —— 一定會遇到。
> 正確做法是補一筆「對帳調整」並寫明原因,而不是去修改或刪除過去的紀錄。
> 這樣帳上永遠看得到曾經差過多少、為什麼差。

## 看每日盈虧(日曆)

每一格是那天**股票市值的變化**,已經扣掉當天買賣造成的部位變動 ——
買進 50 萬不是賺 50 萬,那只是現金換成股票;手續費與稅則算成當天的損失。
紅色是賺、綠色是賠(台股慣例),底色越深代表那天的波動在當月越大。

| 格子上的標示 | 意思 |
|---|---|
| 右上角的小點 | 那天有買進、賣出或導入持股,顏色見日曆下方的圖例 |
| 節日名稱(例如「中秋節」) | 國定假日休市,來自證交所的年度行事曆 |
| 休市 | 行事曆沒列到、但那天沒有收盤價(例如颱風假) |
| 待更新 | 那天有開盤,但收盤價還沒抓到,等下一次同步 |
| 導入 | 導入既有持股的那天,不計盈虧 |

- **月合計**在月份切換的右邊:當月每一格的加總、月報酬率,以及漲跌各幾天。
- **12 個月列**在日曆上方:今年每個月一格,點一格跳到那個月;右上是今年合計。
- **點某一天**會在下方列出每檔的明細(名稱與代號、股數、前日與當日收盤、漲跌幅、盈虧),加總等於那一格。

日曆的全年加總跟總覽「年度損益」的合計會差一點:日曆在導入既有持股那天不算盈虧,
年度表則是跟你輸入的成本比。兩個都對,回答的問題不一樣。

## 總覽的年度損益表

每年當成一段期間結算,只看股票、不含現金:

```
當年總損益 = 期末股票市值 − 期初股票市值 − 當年買入 + 當年賣出實收
```

扣掉當年賣出結算的**已實現**,剩下的就是當年的**未實現**(帳面的變動)。
點任何一列可以看這條算式的每一項,方便拿券商對帳單核對。「全部」那列是各年加總。

賣出的那一年,之前累積的帳面獲利會從未實現搬到已實現,所以那年的未實現可能是負的 —— 那不是虧損。

## 五條要先理解的規則

這幾點跟一般記帳軟體不太一樣,先看過會少走很多冤枉路。

1. **餘額是算出來的。** 帳戶沒有可以直接編輯的總額欄位。
   餘額 = 期初餘額 + 之後所有收支的累加。想改餘額,只能新增一筆收支。

2. **券商帳戶不用手動維護。** 記錄股票買賣時,系統會自動在對應的券商帳戶產生一筆收支。
   這些紀錄在流水帳裡會標示「股票交易自動連動」,不能單獨刪除。

3. **期初只有一筆。** 每個帳戶只能有一筆期初餘額,每人每檔股票只能有一筆期初持股。
   帳戶的期初餘額是起算點,不能刪除;股票的期初持股可以編輯或刪除(例如導入日期填錯)。

4. **家人的資料唯讀。** 切到「全家」視角看得到所有人的帳戶與持股,但只能修改自己的。
   別人的帳戶會標示「唯讀」。

5. **數字每天自動更新。** 平日台灣時間 14:30(台股收盤後)與隔天 06:30(美股收盤後)
   各抓一次收盤價與美元匯率。首頁主數字與持股是即時算的;趨勢圖與日曆用的是每日快照,
   補登、編輯或刪除過去的交易後,會在下一次同步時自動從那天重算。

## 常見狀況

| 狀況 | 怎麼辦 |
|---|---|
| 總資產是 NT$0 | 還沒建立任何帳戶或持股,先做完「第一次設定」的第 3、4 步 |
| 某檔股票寫「報價未同步」 | 排程還沒抓到那一檔,市值會**暫時以成本價估算**,不會讓總資產憑空少一塊。如果隔天還是這樣,先確認股票代號有沒有打錯 |
| 設定頁顯示「尚未同步」 | 每日排程沒跑成功。到 GitHub repo 的 Actions 分頁看是哪一步失敗 |
| 找不到「個人 / 全家」切換 | 家庭裡只有你一個人時不會顯示,等家人用邀請碼加入後就會出現 |
| 日曆某一格跟點開的明細對不起來 | 剛補登、編輯或刪除了過去的交易。明細是即時算的,格子要等下一次每日同步重算,同步跑過就會一致 |
| 補登了一檔以前沒買過的股票,日期在過去 | 那段期間的歷史價格要另外補抓:到 GitHub repo 的 Actions 分頁執行「回填歷史資產快照」 |
| 領到的股息沒有算進損益 | 系統目前沒有配息功能。先在券商或銀行帳戶記一筆「存入」,現金與總資產會正確,但不會算進股票損益 |
| 某筆帳戶紀錄刪不掉 | 期初餘額不能刪(它是起算點);股票連動產生的要回股票頁刪原本那筆買賣 |
| 一直登不進去 | 如果訊息是「這個帳號還沒完成 Email 驗證」,去收信點驗證連結 —— 不是密碼的問題,再怎麼重打都不會過 |
| 忘記密碼 | 登入頁密碼欄下方點「忘記密碼?」,輸入 Email 後收信,點信裡的連結設定新密碼 |
| 重設連結打開說「已經失效」 | 連結只能用一次、一小時內有效。也可能是在不同的瀏覽器打開(例如用郵件 App 內建瀏覽器),回登入頁重新申請一次,並在同一個瀏覽器打開 |
