# 使用手冊

給實際使用這套系統的人看的。部署與環境設定請看根目錄的 [README](../README.md)。

記錄股票買賣與銀行帳戶餘額,每天自動抓收盤價與匯率,在首頁看資產配置與增長趨勢。
家人可以共用同一份資料,各自只改自己的部分。

---

## 第一次設定

照順序走完這五步,之後就只需要記錄新發生的買賣與現金進出。

### 1. 註冊帳號

填 Email、密碼與顯示名稱。密碼至少 8 個字元。

如果送出後看到「請到信箱點擊驗證信」,先去收信完成驗證再回來登入。

### 2. 建立家庭,或加入家人的家庭

第一個註冊的人選「建立新家庭」,取個名字就好。
其他家人選「加入既有家庭」,貼上第一個人給的邀請碼。

### 3. 把帳戶建起來(帳戶 → 新增帳戶)

每個銀行帳戶建一個,每個券商建一個「券商虛擬帳戶」。

| 欄位 | 說明 |
|---|---|
| 類型 | 銀行 / 券商虛擬帳戶 |
| 幣別 | 新台幣 / 美元 |
| 機構名稱 | 例如「國泰世華」「元大證券」 |
| 備註 | 選填,例如「薪轉戶」 |
| 期初餘額 | 填你**今天**的實際餘額 |
| 期初日期 | 這個帳戶的起算日 |

### 4. 導入現有持股(股票 → 新增交易 → 期初持股)

手上每一檔股票各記一筆,填目前的**股數**與**均價**,
不用把過去的買賣一筆筆補回來。期初持股不會動到任何帳戶餘額。

### 5. 把邀請碼給家人(設定 → 邀請碼)

複製那串代碼傳給家人。他們註冊後貼上,首頁就會多出「全家」視角。
只有一個人的時候不會顯示這個切換。

> **手機與電腦的版面不一樣。**
> 手機是底部四個分頁、資料以卡片呈現、表單從底部滑上來;
> 電腦是頂部導覽、完整表格、置中對話框。功能完全相同。

## 四個分頁

| 分頁 | 內容 |
|---|---|
| **總覽** | 最上方是總資產,底下四個數字:股票市值、現金、未實現損益、已實現損益。再往下是資產增長曲線與配置圓餅圖。可切「個人 / 全家」與期間(1／3／6 個月,1／3／5 年) |
| **股票** | 上半是目前持股(股數、均價、現價、市值、未實現損益),下半是所有交易紀錄。右上角「新增交易」記錄買賣 |
| **帳戶** | 分成「銀行」與「券商虛擬帳戶」兩組,各自有小計。點任何一個帳戶進去看完整流水帳並新增收支 |
| **設定** | 家庭名稱與成員、邀請碼,以及資料同步狀態 —— 最新股價日期與最新匯率 |

## 記錄股票

股票 → 新增交易,三種類型擇一。
台股打代號會跳出建議清單,選了會自動帶入商品名稱;美股目前要自己填名稱。

| 類型 | 什麼時候用 | 對券商帳戶的影響 |
|---|---|---|
| 期初持股 | 導入既有部位,填目前股數與均價 | **不連動** —— 代表既有部位,不是新的資金進出 |
| 買進 | 新買一筆,填成交價與手續費 | **提出** 股數 × 價格 ＋ 手續費 |
| 賣出 | 賣掉一筆,填成交價與手續費及稅 | **存入** 股數 × 價格 − 手續費與稅 |

買進與賣出的表單上有「同步更新券商帳戶餘額」這個勾選,預設是打開的,
並要你選一個交割用的券商帳戶。某一筆不想連動就取消勾選 —— 那筆交易只會影響持股,不動任何餘額。

> **刪除買賣時,連動產生的帳戶紀錄會一併消失。**
> 所以不要到帳戶頁去刪那筆自動產生的收支(也刪不掉),
> 要改就回股票頁刪掉原本那筆買賣,重記一次。

### 均價是怎麼算的

採**移動加權平均法**。買進會把成本攤進均價,賣出不改變均價
—— 只是按均價把成本移出去,差額計入已實現損益。

以 2330 台積電為例:

| 動作 | 結果 | 算式 |
|---|---|---|
| 期初持股 1,000 股,均價 600 | 均價 600.00 | 總成本 600,000 |
| 買進 1,000 股 @ 800,手續費 400 | 均價 700.20 | (600,000 ＋ 800,000 ＋ 400) ÷ 2,000 股 |
| 賣出 500 股 @ 900,費稅 1,600 | 均價 700.20 | 均價不變,持股剩 1,500 股 |
| ↳ 這筆的已實現損益 | ＋98,300 | (500 × 900 − 1,600) − (500 × 700.20) |

賣光之後再買進,均價會用新的買進價重新起算,但已實現損益是累計的,不會歸零。

## 記錄現金

點進任一帳戶,用「新增收支」記錄。帳戶之間搬錢則用帳戶頁上方的「轉帳」。

| 類型 | 什麼時候用 |
|---|---|
| 存入 | 薪資、利息、他人匯入等進帳 |
| 提出 | 提款、繳款、消費等出帳 |
| 對帳調整 | 帳面跟實際對不起來時補的一筆。**金額可以填負數**,而且請務必寫明原因 |
| 轉帳 | 帳戶之間搬錢。成對記錄(一邊轉出、一邊轉入),總資產不變。只能在自己的帳戶之間轉 |

流水帳的每一列都有「結餘」,是從期初一路累加到那一筆的餘額,
方便你跟銀行對帳時逐筆核對。

> **不要回頭改舊紀錄。**
> 銀行給的利息、忘了記的一筆提款、跨行手續費 —— 一定會遇到。
> 正確做法是補一筆「對帳調整」並寫明原因,而不是去修改或刪除過去的紀錄。
> 這樣帳上永遠看得到曾經差過多少、為什麼差。

## 五條要先理解的規則

這幾點跟一般記帳軟體不太一樣,先看過會少走很多冤枉路。

1. **餘額是算出來的。** 帳戶沒有可以直接編輯的總額欄位。
   餘額 = 期初餘額 + 之後所有收支的累加。想改餘額,只能新增一筆收支。

2. **券商帳戶不用手動維護。** 記錄股票買賣時,系統會自動在對應的券商帳戶產生一筆收支。
   這些紀錄在流水帳裡會標示「股票交易自動連動」,不能單獨刪除。

3. **期初只有一筆。** 每個帳戶只能有一筆期初餘額,每人每檔股票只能有一筆期初持股
   —— 它是起算點,所以不能刪除。

4. **家人的資料唯讀。** 切到「全家」視角看得到所有人的帳戶與持股,但只能修改自己的。
   別人的帳戶會標示「唯讀」。

5. **數字每天自動更新。** 台灣時間 14:30(台股收盤後)與隔天 06:30(美股收盤後)
   各抓一次收盤價與美元匯率。趨勢圖用的是每日快照,首頁主數字則是即時算的。

## 常見狀況

| 狀況 | 怎麼辦 |
|---|---|
| 總資產是 NT$0 | 還沒建立任何帳戶或持股,先做完「第一次設定」的第 3、4 步 |
| 某檔股票寫「報價未同步」 | 排程還沒抓到那一檔,市值會**暫時以成本價估算**,不會讓總資產憑空少一塊。如果隔天還是這樣,先確認股票代號有沒有打錯 |
| 設定頁顯示「尚未同步」 | 每日排程沒跑成功。到 GitHub repo 的 Actions 分頁看是哪一步失敗 |
| 找不到「個人 / 全家」切換 | 家庭裡只有你一個人時不會顯示,等家人用邀請碼加入後就會出現 |
| 某筆帳戶紀錄刪不掉 | 期初餘額不能刪(它是起算點);股票連動產生的要回股票頁刪原本那筆買賣 |
| 一直登不進去 | 如果訊息是「這個帳號還沒完成 Email 驗證」,去收信點驗證連結 —— 不是密碼的問題,再怎麼重打都不會過 |
